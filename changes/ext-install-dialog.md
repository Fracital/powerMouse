### Demo and API

- The extension install dialog reads in every theme. Cancel was black on
  the Default theme's near-black sheet (1.11:1) and Add extension was
  4.41:1 in Light. The dialog now takes the settings dialog's surface and
  the Remove bubble's icon and title, with the extension's 32 px icon
  beside a bold `Add "<name>"?`, "It can:" over plain rows, and Add
  extension (the accent) and Cancel (the raised surface) at the bottom
  right, 20 px in from the edges. Both buttons are 5.9:1 or more in
  Default, Light, Dark and Web Store themes. As in Chrome, the focus
  starts on Cancel and an extension that asks for no permission gets no
  "It can:". The uninstall dialog from the store and the Extensions page
  has the same look. The passkey and site permission sheets' Cancel,
  Block and Close are in the sheet's text colour (webstore suite).
