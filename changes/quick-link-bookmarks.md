### Demo and API

- The demo's bookmarks start with the quick links too (Reddit, Google,
  YouTube and Discord, at the URLs their tiles open, after Fracital,
  vibeOS, Estro and Krunk), and a list seeded before gets them once: the
  seeding marker now keeps the URLs it offered, so a default the user
  removed stays removed. A bookmark keeps its page's description (its meta
  description, else its og:description, asked of the page when it is
  bookmarked) and the sidebar shows it as a muted line under the title
  (demo-bookmarks).
