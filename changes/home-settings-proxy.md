### Demo and API

- The home card has a Settings button beside Customize in the same right-hand
  tab. It opens the same keyboard-accessible dropdown as the browser's
  hamburger, with the existing Themes, Settings, About and vibeOS actions.
- Proxy is a submenu of either dropdown. Block ads, Tor and Transport are
  located there rather than in the home footer, and use their original
  controls and stored settings; turning Tor or Block ads on/off still reloads
  the page. The Proxy submenu keeps its form controls across openings and
  supports a phone's narrower viewport.
