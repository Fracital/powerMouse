### Fidelity

- A document whose policy names the hosts its images, fonts or media may
  come from (img-src, font-src, media-src, default-src) is refused one
  from another host again, as natively, when an earlier document of its
  site left a copy in the renderer's memory cache: such a document's loads
  no longer carry the site's cache mark, so each reaches the service
  worker, which judges it by the real URL. (memory-cache-share suite.)
