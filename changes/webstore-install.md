### Demo and API

- Click **Add to Chrome** on a supported Chrome Web Store listing to install
  an extension in powerMouse. The host shows the permissions and asks for
  confirmation through `controller.extensions.onPrompt`. Cancel downloads
  nothing. After installation, the toolbar shows the extension's action
  and **Remove from Chrome** uninstalls it from powerMouse. The worker
  checks the calling document, approved manifest, listing id, and CRX3
  signatures. The store keeps control of its buttons and notices.
