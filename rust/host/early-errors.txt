# Early errors: scripts a browser refuses to compile, and their neighbours it
# takes. Written from the "Static Semantics: Early Errors" sections of
# ECMA-262 (and Annex B, where a browser takes what the main body refuses),
# by clause. One case a line:
#
#   <sloppy script><strict script><module> <text>
#
# The three marks are V8's verdicts, `+` compiles and `-` SyntaxError, for
# the text as a classic script, as one behind `'use strict';` and a line
# break, and as a module. They are recorded (`node rust/host/early.mjs
# --record` rewrites the column) and held to the V8 that runs the suites
# (rewriter-unit) and to Chrome (the early-errors suite); the crate's tests
# read them, since no V8 runs there. In a text `<NL>` is a line feed, `<CR>`
# a carriage return, `<LS>` and `<PS>` U+2028 and U+2029, `<U+XXXX>` that
# code point; nothing else is escaped. rust/host/early.mjs also runs every
# text inside a function, an arrow, an async function, a generator, a method,
# a static block and a block, with V8 asked each time.
