# What the wasm rewriter (rust/rwjs) does short of V8's answer on the texts
# of rust/host/early-errors.txt, by name: `<kind> <text>` a line. Anything
# short of it that no line here names fails rust/host/early.mjs, the crate's
# tests and the rewriter-unit suite, and so does a line nothing needs any
# more. None of it is a script V8 refuses that runs rewritten, or one V8
# takes that goes out unrewritten: those have no kind to be named as.

# optional chain to a private name assigned to; a quantifier past 2^53).
# The module declines it (status 4) and the JavaScript rewriter decides;
